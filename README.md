# efIQo

An active recall study workspace built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS v4**, **Firebase**, and **Gemini AI**.

## Features

- **Active Recall Flashcard Studio**: Create custom decks with image attachments, 3D tactile card flips, keyboard navigation (`Space`, `←`, `→`), spaced confidence tracking (`Needs Review` / `Got It`), shuffle & missed-only modes, Efi study mnemonics, and JSON export/import.
- **Timed & Untimed Quiz Engine**: Author 4-option multiple-choice quizzes, run untimed or 10-minute timed exam sessions, review line-by-line corrections, and request concise AI explanations with Efi.
- **Lecture-to-Deck Synthesis**: Generate structured flashcards or practice quizzes from any course topic or uploaded PDF lecture (up to 10 MB) via server-side Gemini API routes.
- **Side-by-Side PDF Reader & Pomodoro Timer**: Open local PDFs in distraction-free Focus Mode paired with a 25/5/15 Pomodoro sprint clock and auto-saved study scratchpad.
- **Dual-Theme & Environment Config**: Full Light, Dark, and System theme support with Firebase configuration managed via `.env`.
